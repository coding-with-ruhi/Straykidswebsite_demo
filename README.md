# 🎵 Global STAY Hub

Global STAY Hub is a fan-made website dedicated to Stray Kids and the STAY community. I built this project to create a space where fans can explore some of Stray Kids' music, learn about their journey, and feel connected to the fandom through a visually themed experience.

The website follows a dark red and black aesthetic inspired by Stray Kids' concepts and branding. It features dedicated sections that introduce the group, showcase selected albums and songs, and celebrate the global STAY community.

---

##  Features

* Responsive single-page website
* Stray Kids-themed design and visuals
* About section introducing the group and their journey
* Featured albums with direct Spotify and YouTube access
* Dedicated STAY Hub section for fans
* Smooth scrolling navigation
* Mobile-friendly layout
